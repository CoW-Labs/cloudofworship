# Badge

A small uppercase pill marking a saving or a status next to a label.

**Provide** a `<span class="ds-badge">` with one or two words. It uses `brand-soft` with `brand-text` (4.9:1).

**Use** beside toggle labels (“Annual 10% OFF”) or nav items.
**Don't** put badges on buttons or use more than one per row.

**Group:** Labels

## Markup

```html
<div class="row"><span class="ds-badge">10% off</span><span class="ds-badge">New</span></div>
```
