# TestimonialCard

A real church's words in a lavender-gradient card, signed with the person and church in the display face.

**Provide** a `<figure class="ds-quote-card">` with a `.ds-quote` blockquote, `.ds-quote-who` (name, church) and `.ds-quote-src` (where it was posted).

**Use** only real, attributed reviews; trim with an ellipsis, never rewrite. Prefer quotes that name a concrete situation (children running slides, no budget, flaky Wi-Fi).
**Don't** use stock headshots or star rows in the card.

**Group:** Cards

## Markup

```html
<figure class="ds-quote-card" style="margin:0"><blockquote class="ds-quote">“Used by kids in the children’s ministry every Sunday. That’s how easy it is to use.”</blockquote><figcaption><p class="ds-quote-who">Victor, Foursquare Church</p><p class="ds-quote-src">Review on Trustpilot</p></figcaption></figure>
```
