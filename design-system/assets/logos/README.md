The Cloud of Worship cloud mark, copied from the product's `favicon.svg`. All three share one path at 144×144.

- `cow-mark.svg`: purple gradient (#A855F7 → #8946C9 → #A855F7). Use on `surface`, `surface-wash` and `surface-footer`, and as the app icon and favicon.
- `cow-mark-white.svg`: single ink, #FFFFFF. Use on `surface-stage` and `night`.
- `cow-mark-ink.svg`: single ink, #0C0F19 (`night`). Use on `surface-poster`.

The name is not part of these files; set it in `text-wordmark` beside the mark (see the Logo component).
